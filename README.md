# 🦩🚲 Pelican Grand Tour 3D — 鹈鹕环岛单车奇旅

> Interactive Three.js WebGL Showcase deployed on **GitHub Pages Global CDN**

![Pelican Grand Tour 3D Banner](./public/og_banner.jpg)

## ✨ 核心特性 (Capabilities Showcase)

- **解析式双骨骼逆运动学 (Analytical 3D 2-Bone IK)**：鹈鹕双腿与双脚掌在 360° 曲柄旋转过程中毫秒级精准锁死踏板，双翼自动握持转向车把并在兔跳/翘头特技时展翅扇动。
- **软体弹性喉囊物理 (Soft-Body Gular Pouch Physics)**：基于阻尼弹簧振子 (`Spring1D`) 模拟鹈鹕标志性橙色大喉囊的颠簸回弹与捕鱼吞咽膨胀，捉住跃水银鱼时可见鱼尾摆动。
- **自定义 GLSL 着色器 (Custom GLSL Shaders)**：
  - **Gerstner 多波叠加海浪着色器**：含解析法线高光、菲涅尔天空反射、海岸破碎浪花以及星夜模式下的**生物荧光蓝海浪 (Bioluminescence)**。
  - **瑞利/米氏散射大气天空穹顶**：支持 **🌅 黄金落日 / ☀️ 晴午碧海 / 🌌 荧光星夜 / 🌸 珍珠晨曦** 四种天气光影平滑过渡。
- **复古绿松石公路车精密机械结构**：24 辐条编织轮组、40 节实时滚动链条、Brooks 弹簧真皮坐垫、复古真皮后驮包、前叉动态聚光车灯、黄铜车铃及 AI 生成的 `PELICAN VELO` 车头浮雕徽章。
- **零外部音频文件的多声道 Web Audio 合成器**：实时合成海浪拍岸、破风声、飞轮棘轮咔哒声、双泛音黄铜车铃、鹈鹕滑稽鸣叫与捕鱼马林巴琴欢呼音效。
- **双驾驶模式 & 四机位导演镜头**：支持智能环岛自动巡航与 `WASD` 手动自由骑行，内置 **自由环绕 / 动感跟拍 / 鹈鹕长喙第一视角 (Beak POV) / 直升机航拍大片** 四种机位与实时 2D 雷达小地图。

## ⌨️ 快捷键

| 按键 | 功能 |
| :--- | :--- |
| `M` | 切换 **自动巡航 / WASD 手动自由驾驶** |
| `Shift` | **涡轮破风冲刺**（自动戴好飞行员风镜 + 尾焰粒子） |
| `Space` | **兔跳腾空展翅** (Bunny-Hop) |
| `E` | **单轮翘头特技** (Wheelie) |
| `B` | 敲响**黄铜复古车铃** |
| `Q` | **鹈鹕鸣叫** |
| `G` | 切换额头/眼部 **复古飞行员风镜** |
| `F` | **召唤跃水银沙丁鱼群**供鹈鹕空中捕食 |
| `C` | 切换 **4 种电影相机视角** |
| `P` | 一键导出当前画面 **高清 PNG 截图** |
